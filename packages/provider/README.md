# pigcode_ai_provider

`pigcode_ai_provider` defines provider-neutral contracts for language, embedding,
reranking, image, speech, transcription, and video models; messages and stream
events; tools and approvals; files and skills; middleware; cancellation; and
errors.

```dart
import 'package:pigcode_ai_provider/pigcode_ai_provider.dart';
```

This package is not yet published (publish_to: none).
