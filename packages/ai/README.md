# pigcode_ai

`pigcode_ai` provides the pure Dart SDK core for text and structured object
generation and streaming, embeddings, reranking, images, speech, transcription,
video, file and skill uploads, tools, middleware, UI message conversion, and
telemetry.

```dart
import 'package:pigcode_ai/pigcode_ai.dart';
```

This package is not yet published (publish_to: none).
